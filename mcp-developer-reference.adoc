[[mcp-endpoint]]
== Endpoint MCP

O servidor MCP docs.netapp.com tem um endpoint HTTP remoto que expõe a documentação da NetApp por meio de uma interface MCP padrão. Aplicativos cliente, como o GitHub Copilot no Visual Studio Code, o Claude Desktop, o Cursor e frameworks de agentes Python personalizados, podem se conectar a ele por meio de um cliente MCP compatível.

.Endpoint HTTP
`\https://docs.netapp.com/mcp`

O formato de exemplo a seguir é usado para configurar o servidor MCP usando um  `mcp.json` arquivo no Visual Studio Code. Para obter informações sobre outros clientes MCP compatíveis, consulte link:mcp-server-get-started.html["Comece com o servidor MCP do docs.netapp.com"].

[source, json]
----
{
  "servers": {
    "netapp-docs-mcp": {
      "type": "http",
      "url": "https://docs.netapp.com/mcp",
      "headers": {
        "Ocp-Apim-Subscription-Key": "${input:Ocp-Apim-Subscription-Key}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "Ocp-Apim-Subscription-Key",
      "description": "Enter your access key",
      "password": true
    }
  ]
}
----


[[tools]]
== Ferramentas

O servidor MCP do docs.netapp.com fornece um conjunto de ferramentas pequeno e específico para descoberta e recuperação de documentação. Você não precisa especificar uma ferramenta ao invocar o servidor MCP em seu cliente. O cliente de IA escolhe a ferramenta correta com base na consulta.

O servidor atualmente oferece as seguintes ferramentas:

* `netapp_docs_ask`: Gera respostas derivadas do conteúdo publicado em docs.netapp.com usando um fluxo de trabalho de geração aprimorado por recuperação.
* `netapp_docs_search`: Descobre páginas de documentação relevantes da NetApp usando palavra-chave e consultas em linguagem natural.
* `netapp_docs_fetch`: Recupera o conteúdo estruturado de uma página de documentação ou artigo específico.
* `health_check`: Valida a disponibilidade do servidor MCP.
