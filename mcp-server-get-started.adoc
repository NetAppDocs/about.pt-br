= Comece com o servidor MCP do docs.netapp.com
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Conecte seu ambiente de desenvolvimento de IA ao servidor Model Context Protocol (MCP) do docs.netapp.com. Depois de configurar o servidor MCP, você pode usá-lo para retornar respostas derivadas da documentação técnica do produto publicada em docs.netapp.com.



[[prerequisites]]
== Pré-requisitos

Antes de configurar o servidor MCP docs.netapp.com, verifique o seguinte:

* Você analisou os requisitos e limitações em link:mcp-server-learn.html["Saiba mais sobre o servidor MCP do docs.netapp.com"].
* Você tem acesso a um cliente compatível com MCP, como o Visual Studio Code com GitHub Copilot, Claude Desktop, Cursor ou frameworks de agentes baseados em Python.
* Você precisa ter uma chave de assinatura válida. Se você não fornecer uma chave, as solicitações MCP falharão e retornarão um erro de acesso. Para solicitar uma chave de assinatura, entre em contato com ng-docs-mcp@netapp.com com uma breve descrição do seu caso de uso.
* Você tem acesso à rede ao endpoint MCP do docs.netapp.com: `\https://docs.netapp.com/mcp`.

[[visual-studio-code-setup]]
=== Configuração do Visual Studio Code

Você pode se conectar ao servidor MCP a partir do Visual Studio Code usando o GitHub Copilot, configurando um  `mcp.json` arquivo.

.Antes de começar
* Esta tarefa requer o Visual Studio Code com a extensão GitHub Copilot ativada.


.Passos
. Na sua área de trabalho do projeto no Visual Studio Code, execute as seguintes etapas:
+
.. Crie uma pasta chamada `.vscode`
.. Crie um arquivo dentro da pasta chamado `mcp.json`


. Configure o arquivo  `mcp.json`.
+
[source, json]
----
{
  "servers": {
    "netapp-docs-mcp": {
      "type": "http",
      "url": "https://docs.netapp.com/mcp",
      "headers": {
        "Ocp-Apim-Subscription-Key": "${input:Ocp-Apim-Subscription-Key}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "Ocp-Apim-Subscription-Key",
      "description": "Enter your access key",
      "password": true
    }
  ]
}
----
. Salve o arquivo.
. Opcionalmente, configure o acesso global.
+
Para configurar o servidor MCP docs.netapp.com em todos os projetos e espaços de trabalho do Visual Studio Code, adicione a configuração ao diretório de configurações globais do usuário.

+
** *Windows*: `C:\Users\<your_username>\AppData\Roaming\Code\User\mcp.json`
** *macOS*: `~/Library/Application Support/Code/User/mcp.json`
+
Adicione a definição do servidor:

+
[source, json]
----
{
  "servers": {
    "netapp-docs-mcp": {
      "type": "http",
      "url": "https://docs.netapp.com/mcp",
      "headers": {
        "Ocp-Apim-Subscription-Key": "${input:Ocp-Apim-Subscription-Key}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "Ocp-Apim-Subscription-Key",
      "description": "Enter your access key",
      "password": true
    }
  ]
}
----
+

NOTE: Após modificar o arquivo global `mcp.json`, reinicie o Visual Studio Code para aplicar a configuração.



. Verifique a configuração.
+
.. Abra o Visual Studio Code em seu espaço de trabalho.
.. Confirme se o  `.vscode/mcp.json` arquivo está presente.
.. Faça uma pergunta usando o Copilot.
+
.Exemplo
Quais são as diferenças entre o ONTAP e o Cloud Volumes ONTAP?







[[claude-desktop-configuration]]
=== Configuração do Claude Desktop

Para registrar o servidor MCP docs.netapp.com com o Claude Desktop, atualize o arquivo de configuração:

* *macOS*: `~/Library/Application Support/Claude/claude_desktop_config.json`
* *Windows*: `%APPDATA%\Claude\claude_desktop_config.json`


[source, json]
----
{
  "mcpServers": {
    "netapp-docs-mcp": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://docs.netapp.com/mcp",
        "--header",
        "Ocp-Apim-Subscription-Key:${NETAPP_MCP_KEY}"
      ],
      "env": {
        "NETAPP_MCP_KEY": "paste-your-subscription-key-here"
      }
    }
  }
}
----


[[cursor-configuration]]
=== Configuração do cursor

Para registrar o servidor MCP docs.netapp.com com o Cursor, atualize o arquivo de configuração.

Para aplicar a configuração globalmente, utilize os seguintes caminhos:

* *Mac OS*: `~/.cursor/mcp.json`
* *Windows*: `%USERPROFILE%\.cursor\mcp.json`


Para aplicar a configuração em um único projeto, utilize  `.cursor/mcp.json` no diretório raiz do projeto.


NOTE: Se o arquivo já tiver outros servidores MCP configurados, adicione  `netapp-docs-mcp` dentro do objeto  `mcpServers` existente (certifique-se de adicionar uma vírgula após a entrada anterior). Se não houver a chave  `mcpServers`, adicione a chave no nível superior, ao lado de quaisquer outras configurações.

[source, json]
----
{
  "mcpServers": {
    "netapp-docs-mcp": {
      "url": "https://docs.netapp.com/mcp",
      "headers": {
        "Ocp-Apim-Subscription-Key": "paste-your-subscription-key-here"
      }
    }
  }
}
----


[[python-ai-agent-integration]]
=== Integração de agente de IA em Python

Use esta opção se você estiver criando aplicativos ou agentes de IA que chamam diretamente o servidor MCP.

Seu cliente se conecta ao endpoint do MCP e invoca as ferramentas.

[source, python]
----
client = MCPClient("https://docs.netapp.com/mcp",
  headers={
          "Ocp-Apim-Subscription-Key": "<YOUR_API_KEY>"
      }
  )
response = client.call_tool("netapp_docs_ask", {
    "question": "What are ONTAP upgrade steps?"
})

----


[[use-the-docs-netapp-com-mcp-server]]
== Use o servidor MCP do docs.netapp.com

Após configurar o servidor MCP, você pode interagir com a documentação técnica da NetApp diretamente na interface do cliente de sua preferência.

.Sobre esta tarefa
* O cliente de IA escolhe a ferramenta apropriada para fornecer resultados com base na sua consulta.
* Use perguntas claras e completas em vez de consultas curtas ou vagas.
* As respostas são sempre derivadas da documentação oficial da NetApp.


.Passos
. Abra o chat no seu cliente compatível com MCP.
. Invoque o servidor MCP configurado e faça uma pergunta clara sobre os produtos ou procedimentos da NetApp.
. Revise a resposta.
